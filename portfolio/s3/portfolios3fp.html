S3FP: Spaghetti City Subway Generator

↗ View Full Screen ↗ View Source Code

Concept

My project is an interactive, generative transit map simulator. The core concept explores how urban infrastructure organically grows around geographical constraints and population centers.

Upon loading, the sketch generates a natural barrier—a meandering river—and scatters "demand dots" representing neighborhoods or points of interest. As the user clicks, they act as a city planner, building a subway network that must navigate around the river, serve the population dots, and intelligently route parallel tracks and transfer hubs.

Procedural Geography

On startup, the system generates a random sine-wave river. It then populates the canvas with demand dots using a while-loop and a custom collision function (isPointOnRiver) to strictly ensure no populations spawn in the water.

User-Driven Infrastructure

When the user clicks, the system uses proximity detection (snapping) to connect the new click to existing stations or demand dots. If they click a demand dot, it is removed from the map as it has been successfully "developed."
