S3A1: Subject to Change

↗ Open Website

Concept & Inspiration

This project is a dynamic, interactive script engine inspired by the unpredictability of improvisational theater and the fill-in-the-blank mechanics of Mad Libs. The narrative acts as a meta-commentary on digital existence, following a "SUBJECT" who slowly realizes they are trapped inside a rendered HTML environment overseen by an omnipresent "SYSTEM VOICE."

To fulfill the requirement of creatively interpreting markup languages, the dialogue heavily integrates pseudo-code, JavaScript functions (`console.log`, `throw new Error`), and CSS styling properties (`opacity: 0; transition: 5s ease-out;`) as literal stage directions and spoken lines.

Interactive Mechanics & Chance

The Improv Engine

The core mechanic revolves around an element of chance. When the user interacts with highlighted `var-slot` elements, a JavaScript function randomly selects parameters from predefined arrays containing Roles, Locations, Verbs, and Adjectives. This ensures that every reading of the script is unique, forcing actors to adapt to sudden, absurd context shifts on the fly.

function scrambleNext() {
  ACTIVE_CHOICES = { ROLE: "", LOC: "", ADJ: "", VERB: "" };
  /* Injects a Glitch Notice */
}
Controlled Chaos

To mimic the spontaneity of a live director shouting out new prompts to actors, a "SCRAMBLE DATA" button resets the active variables mid-scene. This visually injects a glitch notice into the DOM, breaking the fourth wall and demanding the performers immediately pivot their characters to match the newly generated data.

Performance Documentation

Documenting the Script

Because the script relies on a random number generator and dynamic DOM manipulation (revealing lines one by one), the piece is inherently transient. To document the performance, I integrated `html2pdf.js`. By clicking "PRINT/SAVE PDF," the user captures the exact configuration of the script at that specific moment. This transforms a fluid, chaotic web experience into a static, printable artifact, preserving a permanent record of the unique "Mad Lib" variant generated during that specific session.
