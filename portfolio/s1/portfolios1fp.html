Concept & Visual Style

This 5-page digital publication serves as an interactive tribute to the queen of avant-pop, Björk. The visual style is designed to reflect her unique intersection of nature, biology, and digital technology. A consistent thematic language is maintained across all pages using vibrant, shifting gradients, a distinct pixelated typeface (Bitcount Grid Double), and organic, floating "bean" shapes for the navigation toolset.

By heavily employing CSS animations (like breathe and floatWiggle), the entire site feels like a living organism, echoing Björk's own "fungal" and biophilic eras.

Information Flow & Navigation

Cadence & Punctuation

The site employs an intentional sequence to guide the viewer. It begins at the "Nucleus" index—a centralized, breathing point of entry. The cadence then shifts to a highly structured, vertical scroll in the "Discography" timeline. This rhythm is deliberately broken in the "Fashions" page, where absolute-positioned image cells scatter across a massive 400vh canvas, forcing a slow, exploratory scroll.

Global Toolset

Navigation is handled through a consistent set of "floating beans." These buttons utilize fixed and absolute positioning (depending on the page's rhythm) to ensure the user can always jump between the Nucleus, Discography, Natura, Fashions, and the interactive Sound Lab without relying on the browser's back button.

Grid & Flexbox Layouts

The publication heavily utilizes CSS layout models. While the timeline heavily relies on display: flex to align the expanding album pills and text groups, the "Sound Lab" fulfills the explicit grid requirement. It uses a 3x3 CSS Grid to perfectly space the interactive audio buttons, keeping them responsive and centered within the viewport.

Directory Schema

To keep the multi-page site organized and ensure no single page exceeds the 5MB limit, all assets are strictly categorized into a logical directory schema. Audio files triggered by the Sound Lab's JavaScript functions are housed separately from the heavy GIF/image assets used in the Discography and Fashion exhibits.
