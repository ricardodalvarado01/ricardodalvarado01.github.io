S1A2: CSS Still Life

↗ View Full Screen ↗ View Source Code

Concept & Abstraction

This CSS Still Life translates a physical, collaborative assemblage sculpture into a two-dimensional digital composition. Operating entirely within a fixed 800x600px container, the piece heavily utilizes CSS styling and HTML nesting to reduce physical objects into pure, abstract code.

The design explores ideas of dematerialization and porous boundaries. The woven grid structures visually echo traditional Japanese sliding screens, functioning as permeable layers that allow background gradients to bleed through. The inclusion of Japanese characters (such as "運命" for fate and "変化" for change) alongside a massive, sharp red cursor creates an intentional tension between analog, physical symbolism and the hyper-digital medium of the web browser.

Technical Execution

Positioning & Z-Index

To establish the illusion of depth without using any external images, the layout relies heavily on absolute and relative positioning. By assigning distinct z-index values, the text, the overlapping screen grids, and the oversized pointer cursor are forced to interact within the strict constraints of the canvas.

Gradients & Transparency

The background utilizes linear-gradient rules to establish mood and lighting, completely removing the need for flat background-color fills. This ambient light filters through the transparent padding and margins of the grid structure, highlighting the relationship between negative space and the rigid CSS box model.

Pseudo-Classes

Structural complexity was achieved without bloating the HTML by utilizing CSS pseudo-elements like ::before and ::after. These were deployed to cast drop shadows and generate the overlapping structural framing of the grid elements directly from the stylesheet.

CSS Animations

To bring the static assemblage to life, CSS keyframe animations were introduced. This introduces a sense of continuous, directional movement to the composition, allowing the abstract elements to hover and interact softly when the user views the live frame.
