Visual Communication System

We used the sandbox constraints to design a visual communication system in which symbolic characters serve as tonal information, cultural signifiers, and identity markers.

Base System

  • We worked within text-only constraints (ASCII environment).
  • We treated characters as visual pixels.
  • We organized them into a value hierarchy from dark → light.
  • Density of symbol = amount of shadow.
  • Spacing = highlight / negative space.
  • Instead of using neutral characters (#, +, .), we replaced tonal markers with culturally loaded symbols.

Structure of Symbol Language

Each celebrity is rendered using a customized value scale composed of symbols that match their cultural archetype.

ASCII art already reduces images into symbolic code. Celebrity culture does something similar. It reduces complex humans into simplified archetypes like ‘queen,’ ‘icon,’ or ‘villain.’ Our system overlays these two reduction processes.

The final portraits are diagrams of how culture codes identity, translated into a digital language system.
