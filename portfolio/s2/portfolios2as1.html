S2AS1: ART OF THE WEB/RING

For this collaborative class assignment, we were tasked with designing and deploying modular code to link all of our individual web publications into a continuous, looping Web Ring. The challenge was to retroactively patch this navigation feature into our pre-existing sites without disrupting their established visual identities or breaking the user experience.

Design & Integration Strategy

The Sticker Motif

Rather than dropping a generic, hyperlinked text block or a standard button onto my page, I designed a specific "sticker" icon to serve as my node in the Web Ring. I thought carefully about how to incorporate this visual within the context of my existing website design. The sticker acts as a diegetic element—it feels like it naturally belongs in the environment rather than looking like an intrusive, mandatory class requirement.

Reassigning Hierarchy

While the obvious solution would be to place the Web Ring link on the starter/home page, I intentionally decided against it. I placed the sticker on the second page of my site, which focuses on the discography. This decision retroactively shifted the hierarchy of my publication, turning a deeper page into an active transit hub.

Controlling User Flow

By burying the exit link on the second page, I actively manipulated the user journey. When a visitor arrives at my site from the previous student's page in the ring, they aren't immediately presented with the exit door. They are forced to wander a bit into my own introductory content, establishing context before they are allowed to hop to the next user's publication.

The Modular Code

The code itself was designed to be lightweight and modular so it could be easily injected into the existing HTML/CSS structure. It connects the fragmented class projects into a single, cohesive network, honoring the early-internet tradition of web rings while prioritizing modern layout constraints.
